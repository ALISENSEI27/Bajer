# BAJER AI — SCAN

ميزة مستقلة لمراجعة **نص** الإعلان العقاري بالعربية. لا تسجيل تلقائي للصفحة أو للمسار، ولا تعديلات على ملفات مشتركة. لم يتوفر مستودع BAJER المشترك؛ لا يُفترض التوافق مع اصطلاحاته غير المرئية.

## الملفات

- `Scan.jsx`: الصفحة؛ تصدير افتراضي وتصدير مسمى `Scan`.
- `scan.css`: أنماط محصورة داخل `.bajer-scan`؛ دون خط خارجي أو تعديل الأنماط العامة.
- `storage.js`: حفظ التقارير المعتمدة وقراءتها وحذف تقرير محدد.
- `index.js`: صادرات الميزة.
- `tests/*.test.mjs`: اختبارات معزولة تستخدم أدوات النسخة المتاحة من المشروع.
- `server/routes/scan.js`: Express router، ومحلل عربي حتمي، ومراجعة AI اختيارية على الخادم.

## الدمج لاحقًا — لا تطبق هذه الخطوات تلقائيًا

انقل مجلد `client/src/features/scan/` وملف `server/routes/scan.js` فقط. يتطلب التنفيذ React وExpress؛ لا يعتمد على مكتبة مكونات أو SDK للذكاء الاصطناعي. الخادم يحتاج Node.js حديثًا مع `fetch` و`AbortController` وWeb Streams (Node 20+؛ اختُبر هنا على Node 24). تنسيق الوحدات ESM مثل scaffold المتاح، **وليس ادعاءً بأن المستودع المشترك يستخدم ESM**.

### واجهة React

من ملف داخل `client/src`:

```jsx
import { Scan } from "./features/scan";

// ضع العنصر داخل المسار المناسب في موجّه المشروع عند الدمج:
<Scan />
```

من أي مسار آخر عدّل مسار الاستيراد النسبي. إن كان البناء لا يدعم استيراد المجلد فاستخدم `./features/scan/index.js`.

المسار الافتراضي للخدمة `/api/scan/analyze`. عند وجود بادئة للمشروع:

```jsx
<Scan analyzeUrl={`${applicationBasePath}/api/scan/analyze`} />
```

وفّر قيمة البادئة من اصطلاحات المشروع الفعلية، دون مضاعفة `/`؛ لا يوجد افتراض بشأن أداة توجيه بعينها. الملف JSX يحتاج build يدعم React JSX وCSS imports، مثل Vite. لا يوجد HTML خام من الإعلان، ولا روابط قابلة للنقر أو `dangerouslySetInnerHTML`.

### Express

مثال في ملف الخادم الموجود داخل `server/` بنمط ESM:

```js
import scanRouter from "./routes/scan.js";

// ضع middleware المصادقة/تحديد المعدل الخاص بالمشروع أمام المسار عند الحاجة.
// يفضل تسجيل هذا المسار قبل محلل JSON العام حتى تبقى أخطاء الحجم/JSON محلية.
app.use("/api/scan", scanRouter);
```

المسار الداخلي هو `/analyze`، لذا تصبح نقطة النهاية:

```http
POST /api/scan/analyze
Content-Type: application/json

{"text":"نص إعلان عقاري يتجاوز عشرين حرفاً"}
```

لا تسجّل المسار باسم `/api/scan/analyze` ثم تضيف إليه `/analyze` مرة أخرى. لا تضف CORS مفتوحًا أو عنوان localhost إلى الواجهة. اضبط بادئة Express و`analyzeUrl` معًا عند الحاجة.

إذا كان المستودع المستهدف CommonJS أو TypeScript-only، تكييف تنسيق الملف جزء من الدمج بعد الاطلاع عليه؛ لم تُعدّل manifest لفرض ESM. لم تُضف هوية أو تخزينًا على الخادم. على المشروع المضيف توفير سياسات الوصول وتحديد المعدل/ميزانية استدعاءات المزود وحماية السجلات إن كان سيعرض الميزة للعامة.

## العقد

`text` هو الحقل الوحيد المقبول؛ طوله بعد إزالة الفراغات لا يقل عن 20، وطوله الأصلي لا يزيد على 12000 حرف، وحد جسم JSON هو 64KB.

النجاح `200`:

```js
{
  mode: "demo" /* أو "ai" */,
  notice: "رسالة عربية تشرح النمط",
  fields: {
    // propertyType, location, price, area, bedrooms,
    // propertyAge, ownership, maintenanceFees
    price: {
      status: "found", // found | missing | unclear
      value: "٨٥٠٬٠٠٠ ريال سعودي", // null للحالتين missing وunclear
      evidence: ["السعر: ٨٥٠٬٠٠٠ ريال سعودي"]
    }
  },
  contradictions: [{ field: "area", message: "...", evidence: ["...", "..."] }],
  questions: ["..."],
  limitations: ["..."]
}
```

المقتطف يختصر الحقول؛ الاستجابة الحقيقية تتضمن الحقول الثمانية دائمًا.

الأخطاء بصيغة `{error:{code,message}}`: ‏400 للنص/JSON غير الصالح، 413 للحجم الزائد، 415 لنوع المحتوى، 500 لفشل داخلي. لا تُعاد أخطاء المزود الخام. فشل AI ليس نجاح AI: تعاد نتيجة `demo` مع تنبيه واضح.

## AI اختياري — على الخادم فقط

لا يوجد مزود مهيأ في هذه البيئة، ولم تُجرَ مكالمة فعلية إلى AI. لا تحتاج الميزة مزودًا لكي يعمل الاستخراج التجريبي.

يدعم المحوّل الحالي OpenAI عبر عنوان ثابت `https://api.openai.com/v1/chat/completions`. يفعَّل فقط عند إعداد **جميع** ما يلي في بيئة الخادم:

- `SCAN_AI_PROVIDER=openai`
- `SCAN_OPENAI_MODEL`: اسم نموذج يدعم Chat Completions وJSON mode.
- `SCAN_OPENAI_API_KEY`: سر الخادم؛ لا تستخدم بادئة `VITE_` ولا تضعه في الواجهة.

التحقق المحلي من الإعدادات لا يثبت صلاحية الاشتراك أو المفتاح. يُكتشف فشل الاعتماد أثناء الاستدعاء ويظهر الوضع التجريبي بدل الادعاء بعمل AI.

لا يُفعَّل مزود تلقائيًا ولا تُقرأ أسرار عامة لمجرد وجودها. إعداد تكامل آخر لاحقًا يحتاج محولًا صريحًا. عند التفعيل، يُرسل نص الإعلان إلى OpenAI؛ يجب إبلاغ مستخدمي التطبيق بسياسة الخصوصية المناسبة. مهلة الخادم 10 ثوانٍ؛ مهلة الواجهة 25 ثانية؛ حد قراءة رد المزود 100KB. لا أدوات ولا جلب لروابط الإعلان، وتُرفض إعادة التوجيه.

**النطاق المحافظ لـ AI:** يراجع المرشحات الحتمية ويعيد JSON. يُفحص مخطط الحقول والحالات والقيم والاقتباسات، ثم يُشترط التطابق مع الاستخراج المستقل. لا يُسمح لـ AI بإضافة استنتاجات لا تؤيدها القواعد. أي اختلاف يعيد النتيجة التجريبية؛ لذلك قد تُرفض حتى مخرجات AI مفيدة لغويًا. التناقضات والأسئلة تُولَّد حتميًا، لا من ادعاءات النموذج. النمط `ai` يعني اجتياز مراجعة إضافية للنص، لا صحة العقار أو تحققًا رسميًا.

## الاستخراج وحدوده

- يحافظ على الاقتباسات والأرقام الأصلية، ويفهم الأرقام العربية والفارسية في المطابقة.
- لا يحوّل الأسعار أو الوحدات ولا يستنتج عملة أو وحدة غير مذكورة.
- `missing`: لا ذكر مناسب للحقل. `unclear`: ذكر ملتبس/تقريبي/منفي أو قيم متعددة؛ القيمة `null`.
- القيم المذكورة هي **ادعاءات النص فقط** وليست حقائق خارجية.
- التناقضات مقصورة على قيم رقمية مختلفة بوحدة/عملة وصياغة قابلة للمقارنة، أو وجود صك وعدم وجوده صراحةً. القيم ذات العملات/الوحدات المختلفة لا تُعلن تناقضًا.
- الصياغات غير المألوفة، الأعداد المكتوبة بالكلمات، المواقع غير المعلّمة وبعض الوحدات قد تفوت المحلل. الإعلانات متعددة العقارات أو التي تعرض بدائل تحتاج مراجعة بشرية؛ لا يحاول المحلل فهمها كاملة.
- لا صور/PDF، لا فحص أمني للروابط ولا تأكيد لأمانها، ولا تنفيذ تعليمات الإعلان.

## الاعتماد والتخزين

يجب مراجعة الحقول وتحديد الحالات، ثم تفعيل مربع الموافقة قبل الحفظ. أي تعديل يعيد الموافقة إلى غير محددة. لا تُقبل قيمة فارغة لحقل حالته `found`. تحفظ النتيجة الأصلية منفصلة عن نسخة المستخدم المعتمدة.

`localStorage`، المفتاح `bajer.scan.reports.v1`، حد 30 تقريرًا. التقارير تتضمن النص الأصلي والاقتباسات، وهي نص واضح على هذا المتصفح، وليست تخزينًا سحابيًا أو مساحة حساب منفصلة. يمكن لنفس أصل الموقع/مستخدمي المتصفح قراءتها. لا تُلصق معلومات شخصية. الحذف يتم لتقرير SCAN المحدد فقط، لا لكل بيانات الموقع. تلف التخزين/تعطيله/امتلاؤه ينتج رسالة مفيدة، ولا يستبدل البيانات التالفة بصمت. ليست مزامنة بين علامات تبويب متزامنة؛ إعادة التحميل تقرأ آخر نسخة محفوظة.

## تشغيل الاختبارات هنا

من جذر النسخة المتاحة:

```sh
node --test client/src/features/scan/tests/*.test.mjs
```

تستعير الاختبارات `esbuild` وExpress من `artifacts/api-server`، وReact/ReactDOM من `artifacts/mockup-sandbox` دون تثبيت أو تعديل manifests. تبني وحدات الاختبار في الذاكرة فقط. عند نقلها إلى المستودع المشترك، يجب تكييف دقة مسارات أدوات الاختبار مع بنية ذلك المستودع؛ هذه المسارات ليست اعتماد تشغيل للميزة.

التغطية: إعلان مفصل وإعلان ناقص ومتعارض؛ أرقام عربية وفارسية؛ اقتباسات وحالات null؛ رفض مخرجات AI غير المسندة؛ فشل/مهلة مزود **محاكى**؛ طلبات HTTP ضد Express مؤقتًا في الاختبار؛ التخزين وأخطاؤه؛ بناء JSX وعرض React على الخادم.

**غير مختبَر:** الربط مع مسارات/تخطيط المشروع المشترك، التفاعل في متصفح حقيقي، العرض المرئي بلقطة شاشة، واستدعاء مزود حقيقي. لا توجد صفحة مسجلة في scaffold الحالي؛ لم نُعدّل ملفات خارج الملكية لجعلها تظهر. اختبارات React SSR لا تثبت عمل النقرات في المتصفح.

**النتيجة الفعلية في هذه النسخة:** نجح الأمر أعلاه: 18 اختبارًا، 18 ناجحًا، صفر فشل. منها 12 اختبارًا للاستخراج/المزود المحاكى/Express، و6 لبناء وعرض React الأولي والتخزين. لا توجد اختبارات متخطاة. تستخدم الأنماط `@scope`؛ يحتاج العرض متصفحًا حديثًا يدعمه.
